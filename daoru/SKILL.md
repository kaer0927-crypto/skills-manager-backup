# 通用 Excel 批量导入模板

## 当使用此技能

- 需要为某个业务表单（资产、人员、合同、商品等）新建或重新生成 Excel 批量导入模板
- 需要把一张已有导入模板还原成统一的通用结构，或检查其表头、冻结、合并、样式是否走样
- 需要把模板交给业务人员填写，或纳入前端/后端的导入联调
- 需要修改导入模板的列、字段名、必填标记、逻辑说明或模块分组

## 核心定位

本技能是一个**公共导入模块**，只沉淀导入模板的**通用结构、视觉规范与校验能力**，不内置任何业务的字段、列或文案。

- 字段列名、必填标记、字段逻辑说明、模块分组全部由入参决定
- 不得默认写入“某业务系统”“某业务实体”等具体业务的定性内容
- 不得固定列数、列名、列宽或业务取值
- 所有业务字段必须来自用户提供的表单字段说明，不得编造

## 模板固定结构

模板始终为单工作表，表头占前 4 行，第 5 行起为预格式化空白数据行。

1. **第 1 行**：填写说明，跨 A1 到最后一列合并。
2. **第 2 行**：模块分组行；若存在模块划分则按模块合并单元格，否则整行单一说明或留空模块。
3. **第 3 行**：字段名列；必填字段名末尾为红色 `*`。
4. **第 4 行**：逐列字段逻辑说明。
5. **第 5 行起**：空白数据区，行高统一，无示例数据。

## 调用前强制确认

生成、修改或校验前，必须确认以下入参；缺失任何一项应先反问，不得自行推断：

1. **业务表单名称**：本次模板服务于哪个表单
2. **字段清单**：字段名、是否必填、字段逻辑说明
3. **模块划分**：表单是否按模块分组；若是，提供模块名与字段归属
4. **输出文件名**：默认 `导入模板.xlsx`，可由用户指定

反问示例：

> 请提供本次导入模板的表单名称、字段清单（字段名 / 是否必填 / 字段逻辑说明），以及是否按模块分组（模块名与字段归属）。

确认规则：

- 不得根据文件名、历史模板或通用经验推断具体字段
- 用户只给表单名未给字段时，继续追问字段清单
- 未确认前不得运行生成器、修改母版或给出“已对齐”结论

## 工作流

### 1. 确认入参

先完成“调用前强制确认”。拿到表单名称、字段清单、模块划分、输出路径后再进入生成。

### 2. 定义模板

把字段清单整理成结构化定义，至少包含：

- 模块顺序（无模块时为单一分组）
- 每个字段：列名、是否必填、字段逻辑说明

模块与字段示例：

```text
模块：基本信息
  字段名：名称       必填：是   逻辑：最多 99 个字符
  字段名：分类       必填：是   逻辑：填写国标大类原文
模块：财务信息
  字段名：原值(元)   必填：是   逻辑：数字 0 ~ 99,999,999.99
```

### 3. 生成模板

```bash
python3 scripts/generate_template.py \
  --fields fields.json \
  --output ./导入模板.xlsx
```

入参 `fields.json` 为字段与模块定义（结构见 `references/template-spec.md`）。
目标文件已存在时默认拒绝覆盖，需加 `--force`。

### 4. 校验模板

```bash
python3 scripts/validate_template.py ./导入模板.xlsx --spec fields.json
```

校验器检查通用结构：工作表名、表头 4 行、冻结窗格、模块合并、字段名与必填星号、字段逻辑说明、空白数据区，以及无下拉、筛选、表格对象、条件格式、打印区域等禁止能力。

### 5. 交付

交付时报告：

- 输出文件绝对路径
- 文件大小
- 字段数量、模块数量、必填数量
- 校验器结果
- 是否完成 Excel/WPS 视觉渲染检查；未完成时如实说明

## 视觉与样式规范

通用视觉 token（具体色值见 `references/template-spec.md`）：

- 第 1 行填写说明：左对齐、垂直居中、自动换行、浅灰填充、11pt 加粗
- 第 2 行模块分组：水平/垂直居中、浅灰填充、11pt 加粗
- 第 3 行字段名：水平/垂直居中、自动换行、浅灰填充、11pt 加粗；必填星号为红色加粗富文本
- 第 4 行字段逻辑：左对齐、垂直靠上、自动换行、9pt、次要灰字
- 表头边框统一细线
- 冻结窗格固定为 `A5`
- 第 5 行起空白数据行行高统一

## 禁止项

- 不写死任何业务字段、列名、列宽或取值
- 不出现绑定某一具体业务系统或实体的定性文案
- 不新增 Excel 数据验证下拉、自动筛选、表格对象、条件格式、打印区域、页眉页脚
- 不新增示例数据、占位内容或公式
- 不把模板扩展为标签打印、条码或仓储分区设计

## 资源

- `references/template-spec.md`：通用结构与样式规范、字段 JSON 结构
- `scripts/template_contract.py`：结构常量与通用校验逻辑
- `scripts/generate_template.py`：依据字段定义生成模板
- `scripts/validate_template.py`：校验通用结构与样式
- `tests/test_template.py`：生成、校验与故障注入测试

## 验证

```bash
python3 -m unittest discover -s tests -v
```

## 已知限制

- 校验器检查通用结构、样式与禁止能力，不替代 Excel/WPS 的人工视觉检查。
- 校验器面向空白模板；已填写数据的导入文件应由业务系统导入校验处理，不应直接套用本校验器。
- 技能不生成业务字段，不编造任何表单取值。
- 业务字段与模块分组必须由用户在对话中明确提供。
