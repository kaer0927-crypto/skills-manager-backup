# 兰州公物仓资产批量导入模板

## 当使用此技能

- 需要新建或重新生成《兰州公物仓_资产批量导入模板.xlsx》
- 需要检查导入模板的列、表头、合并单元格、颜色、字体、列宽、行高或冻结窗格是否走样
- 需要把模板交给业务人员填写，或把模板纳入前端/后端的导入联调
- 需要修改模板样式，但必须保持既有 35 列业务字段和四层表头结构

## 核心原则

1. `assets/兰州公物仓_资产批量导入模板.xlsx` 是唯一视觉与格式母版，不得凭记忆重画。
2. 模板固定为 1 个工作表、35 列 A:AI、前 4 行为表头、第 5 至 1113 行为预格式化空白数据行。
3. 必填列只用表头中的红色 `*` 表达；不得新增下拉、筛选、表格对象、条件格式或示例数据。
4. 原模板没有数据验证下拉。填写说明中的“下拉类字段”是业务提示，不是 Excel 下拉控件，不得擅自补控件。
5. 不得新增、删除、改名或重排业务字段。字段变更必须先完成业务确认并同步更新母版、规范文档和校验器。
6. 不得把需求分析过程、内部编号、字段计数或实现说明写入模板界面。

## 调用前强制确认

调用本技能后，在生成、修改或校验模板之前，必须先检查当前对话是否已经明确说明以下两项：

1. 模板对应的业务说明或字段说明。
2. 模板与哪个功能表单对齐，以及需要对齐的具体表单字段。

如果对话中没有说明，必须先停止执行并反问用户：

> 本模板需要与哪个功能表单对齐？请提供功能表单名称；如有对应的表单字段说明或字段清单，请一并提供。

确认规则：

- 不得根据文件名、现有 35 列字段、原型页面或通用仓储经验自行推断目标功能表单。
- 用户只给出功能名称、但没有字段说明时，继续询问需要对齐的具体表单字段。
- 用户明确表示“沿用现有模板字段，无需新增或调整字段”时，可视为字段对齐范围已确认。
- 未取得上述确认前，不得运行生成器、修改母版、生成新模板或给出“已对齐”的结论。
- 校验任务同样适用；如用户只是检查既有模板是否符合既定功能表单，也必须先确认目标功能表单和字段范围。

## 工作流

### 0. 确认对齐对象

先执行“调用前强制确认”。确认目标功能表单、字段说明和本次是否需要调整字段后，再进入后续步骤。

### 1. 先读规范

生成或修改前，必须阅读：

- `references/template-spec.md`
- `assets/兰州公物仓_资产批量导入模板.xlsx`

### 2. 生成模板

默认输出到当前目录：

```bash
python3 scripts/generate_template.py
```

指定输出路径：

```bash
python3 scripts/generate_template.py --output path/to/兰州公物仓_资产批量导入模板.xlsx
```

生成器执行字节级复制，确保母版中的列宽、行高、富文本、合并单元格和 XML 维度不被重写。目标文件已存在时默认拒绝覆盖；只有用户明确同意后才可加 `--force`。

### 3. 校验模板

```bash
python3 scripts/validate_template.py path/to/兰州公物仓_资产批量导入模板.xlsx
```

校验通过时退出码为 `0`；任一项不符合时退出码为 `1`，并逐项输出失败原因。

### 4. 修改模板

如确需修改样式或字段：

1. 先确认变更属于业务确认范围，不得自行扩展。
2. 在副本上修改母版，禁止直接覆盖用户现有模板。
3. 同步更新 `references/template-spec.md`。
4. 重新运行生成器与校验器。
5. 重新核对红色星号列、A1 填写说明、四组表头合并范围和第 5 至 1113 行行高。

### 5. 交付

交付时报告：

- 输出文件绝对路径
- 文件大小与 SHA-256
- 校验器结果
- 是否完成 Excel/WPS 视觉渲染检查；未完成时必须如实说明

## 模板硬约束

### 工作表与范围

- 工作表名：`导入模板`
- 列数：35 列，A:AI
- XML 使用范围：`A1:AI1113`
- 合并单元格：
  - `A1:AI1`
  - `A2:J2`
  - `K2:N2`
  - `O2:AD2`
  - `AE2:AI2`
- 冻结窗格：`A5`
- 前 4 行行高：`78 / 26 / 24 / 84`
- 第 5 至 1113 行行高：`30`

### 表头结构

- 第 1 行：填写说明，跨 A:AI 合并
- 第 2 行：四个业务分组
- 第 3 行：35 个字段列名，必填列末尾为红色 `*`
- 第 4 行：逐列填写要求

### 必填列

`B 资产名称`、`C 资产分类`、`F 计量单位`、`G 数量`、`K 资产来源`、`N 取得日期`、`O 账面原值(元)`、`P 价值类型`、`Q 财务入账状态`、`R 折旧/摊销状态`、`AE 存放仓库`、`AF 入库日期`、`AG 实物成色`、`AH 资产业务状态`。

### 禁止项

- 不新增 Excel 数据验证下拉
- 不新增自动筛选、表格对象、条件格式、打印区域或页眉页脚
- 不新增示例资产、占位数据或公式
- 不改变 35 列顺序、列宽、行高、字体、填充和边框
- 不把必填星号改成普通文本或移出红色富文本片段
- 不把模板扩展为实物标签、条码或仓储分区设计

## 资源

- `assets/兰州公物仓_资产批量导入模板.xlsx`：黄金母版，字节级生成来源
- `references/template-spec.md`：完整格式、字段和填写要求
- `scripts/generate_template.py`：安全生成模板
- `scripts/validate_template.py`：结构与样式校验
- `tests/test_template.py`：生成、校验和故障注入测试

## 验证

```bash
python3 -m unittest discover -s tests -v
```

测试覆盖：

- 母版可被校验器通过
- 生成文件与母版字节一致
- 改表头、改列宽、删合并单元格、加数据验证时校验器失败

## 已知限制

- 校验器检查 XLSX 结构与样式，不替代 Excel/WPS 的人工视觉检查。
- 校验器面向空白模板；已填写业务数据的导入文件应由后端导入校验处理，不应直接套用本模板校验器。
- 本技能不生成下拉控件，不添加任何业务字段或示例数据。
- 技能无法仅凭 XLSX 自动判断业务上应对齐哪个功能表单，必须由用户在对话中明确确认。
