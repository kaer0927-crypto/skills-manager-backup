# 数据列表 CRUD 规范（增删改查）

> 基于模板 `list-search-table.js`（ProTable 主范式）的真实交互提炼，适用于所有数据列表页面。
> 核心原则：**新增/编辑用弹窗表单 + 回填 + 校验；删除/批量删除用确认弹窗（danger）；每个操作后 Toast 反馈 + 重查列表**。

## 操作列（每行的编辑/删除）

- 操作列固定在表格最右，按钮用**文本按钮**：编辑（普通色）+ 删除（`status: danger` 红色文本）
- 删除按钮必须红色（danger），与编辑视觉区分
- 操作列宽约 120–160px，不挤占数据列

## 新增（Create）

1. 工具栏左上角放「新增」按钮（primary，实底主色）
2. 点击打开**弹窗表单**（Modal，尺寸按主题弹窗规范：440px，字段多可 560px）
3. 表单初始为空，打开时**清空上一次校验状态**（clearValidate）
4. 保存流程：校验表单 → 校验通过后按钮进入 loading（saving）→ 提交成功 → Toast 成功提示（如「新增成功」）→ 关闭弹窗 → **回到第 1 页重查列表**
5. 校验失败：红环 + 字段错误短句（见主题表单规范），不关闭弹窗

## 编辑（Update）

1. 点击行内「编辑」→ 打开同一弹窗表单（与新增共用），**表单回填该行数据**（id 隐藏携带）
2. 弹窗标题切换：新增态「新增 XX」/ 编辑态「编辑 XX」
3. 保存流程同新增：校验 → loading → 提交成功 Toast（如「更新成功」）→ 关闭弹窗 → 重查列表
4. 若详情面板（抽屉/详情区）正展示该行，更新后**同步刷新详情内容**
5. 保存成功后回到**当前页**（编辑不跳页；新增才回第 1 页）

## 删除（Delete）

1. 点击行内「删除」→ 先弹**确认弹窗**：
   - 标题「删除」，正文「确定删除该条记录？」，确认按钮文案「删除」且 `status: danger`，取消「取消」
2. 确认后：删除 → Toast 成功提示（如「删除成功」）→ 重查列表
3. **删空回退页码**：若当前页删完后该页无数据且不是第 1 页，页码自动回退一页再刷新，避免空页
4. 若详情面板正展示该行，删除后**关闭详情**

## 批量操作（Batch）

1. 表格开启行勾选（checkbox），工具栏放「批量删除」等批量按钮
2. **未勾选任何行时批量按钮禁用**（disabled）；勾选后启用
3. 点击批量删除 → 确认弹窗（标题「批量删除」，正文说明将删除 N 条，确认按钮 danger）→ 删除 → Toast 提示「删除成功（N 条）」→ 重查列表
4. 页码回退规则同单删：当前页数据被删空则回退一页

## 查询 / 分页（Read）

1. 筛选区按「筛选区布局」规范（一行 6 字段栅格，按钮同行）
2. 表格底部固定分页条：共 X 条 · 当前第 N 页 · 每页条数可选（默认 10 条/页，支持切换）
3. 分页变化（翻页/改每页条数）触发重查，不重置筛选条件
4. 详情查看：行点击或「查看详情」按钮 → 打开右侧抽屉/详情面板（左列表右详情用 list-master-detail 骨架）

## 导出（Export）

1. 工具栏放「导出」按钮（outline/secondary），紧跟批量操作之后
2. 导出动作：选择导出格式（**CSV / XLSX** 二选一）→ 确认导出 → 按钮进入导出中状态（exporting，loading）→ 成功 Toast（如「导出成功，共 N 条」）
3. 导出范围与当前筛选/勾选一致；导出中防重复点击
4. 完成后可提供下载入口（如「账单导出任务已完成，可下载」通知/按钮）

## 行内编辑模式（list-editable）

1. 行内编辑：点击行内「编辑」→ 该行字段变输入控件（input/select），行尾提供「保存」「取消」
2. 保存：单行保存（saveRow）Toast「保存成功」；顶部「保存全部」批量保存（saveAll）Toast「已保存全部修改」
3. **未保存警告**：存在未保存修改时切换行/离开页面/批量操作，先弹确认（savedWarn「存在未保存的修改」），防丢失
4. 行内编辑与批量删除可共存（勾选 + 批量删除按钮）

## 反馈与刷新通则

- 所有操作成功必有 Toast 反馈（顶中、主题柔影）
- 所有写操作（增/删/改/批量）后必**重查列表**，保证数据一致
- 失败场景：校验失败红环提示；提交失败 Toast 错误提示并保持弹窗
- 保存按钮在提交期间 loading，防止重复提交

## 自查清单（产出后逐条过）

1. 操作列编辑/删除按钮齐全，删除为红色文本按钮？
2. 新增/编辑共用弹窗表单，编辑能回填该行数据、标题能区分增/改？
3. 删除/批量删除都有 danger 确认弹窗，未勾选时批量按钮禁用？
4. 每个写操作后都有 Toast + 重查列表；删空回退页码？
5. 分页条完整（总数/页码/每页条数）且操作后页码正确？
