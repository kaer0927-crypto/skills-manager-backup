# operation-manual

面向业务信息系统（政务 / 国企 / 机关后勤类 Web/APP）的最终用户操作手册生成 Skill。

## 安装

把整个 `operation-manual/` 目录放到你项目的 `.agents/skills/` 下：

```
你的项目/
└── .agents/
    └── skills/
        └── operation-manual/
            └── SKILL.md
```

Claude Code / Codex / 其他兼容 Agent Skills 标准的工具会自动加载。

## 触发方式

在对话里自然说：

- "帮我写一份 XX 资产系统的用户操作手册"
- "这个原型出一份管理员操作手册"
- "给这个公车管理系统写个培训材料"
- "把这个 PRD 转成用户使用说明书"

AI 会自动加载本 skill。

## 它会怎么工作

1. 先问你 4 件事：系统名、角色、界面素材（Axure/截图/PRD）、导出格式。
2. 没拿到素材前只列大纲，不瞎写按钮名。
3. 按"管理员 / 经办人 / 审批人 / 领导"分角色章节写。
4. 第二人称 + 【】标注界面元素，不可逆操作加 ⚠️ 警示。
5. 写完对着原型校验一遍，不一致的地方列"待确认清单"。
6. 调 docx skill 导出 Word，封面/目录/政务蓝标题配齐。

## 适配你自己的系统

打开 `SKILL.md` 第 4 节"章节结构"，把示例里的"资产登记 / 资产领用"换成你实际的业务模块（公务用车申请、会议室预定、办公用品领用等）。第 5 节是单条操作模板，照抄格式改内容就行。
