# 前端 Demo 质量红线与 B 端交互规范（自包含版）

> 源自 20+ 次真实项目纠偏沉淀。违反红线 = 必被打回，没有例外、没有"先这样后面再改"。

## 一、动手前必做的 5 项分析（Pre-Flight）

1. **用户角色确认**：列出所有角色 + 技术水平。目标用户是非技术人员时，所有文案交互按"完全不懂技术的人"设计
2. **状态机设计**：任何流程/任务类模块先画状态机，**最少 3 态**（禁止只有"进行中/已完成"），考虑中间态、终态后操作、异常态
3. **正/逆操作矩阵**：每个交互控件列出正向 + 逆向操作 + 边界态（全选/取消全选/半选；选中/取消；下一步/上一步）
4. **模块间一致性**：同类功能（上传弹窗、搜索、详情展示）列出统一标准
5. **需求逐条对标**：需求逐条编号，做完逐条打 ✅/❌，不得"大概做完了"

## 二、10 条红线

| # | 红线 | 最低标准 |
|---|------|---------|
| R01 | **文案零英文** | 用户可见文案 100% 中文（"Pipeline Status: Running" → "流程状态：执行中"）|
| R02 | **按钮必绑事件** | 禁止无 onClick 或空函数；Demo 至少 `message.info('功能演示')` |
| R03 | **列表页三件套** | 搜索 + 过滤 + 分页，缺一 = 残缺 |
| R04 | **实体管理必有 CRUD** | "XX管理"页面必须有新建/查看/编辑/删除全套；只做展示 = 不及格 |
| R05 | **控件双向操作** | 可选中就可取消；有过滤就有清除；可添加就可移除；全选支持三态 |
| R06 | **流程三方向** | 步骤条必须支持前进、后退、重置 |
| R07 | **列表数据必过滤** | 按业务状态过滤展示，不得全量混排 |
| R08 | **禁止占位文字** | 一切区域用真实可信的 Mock 数据，禁止 TODO/示例内容/lorem ipsum |
| R09 | **状态不少于三态** | 任务/工单/流程类实体状态枚举 ≥3（草稿/进行中/已完成 起步）|
| R10 | **同类组件统一** | 同类弹窗/列表/空态的行为与视觉一致 |

## 三、B 端交互速查

**页面布局**：列表页 = 顶部筛选栏+操作按钮+表格+分页；详情页 = 标题区+信息分组卡片+返回；表单页 = 表单+底部操作栏（必填标识+校验）；看板页 = 统计卡+图表+明细；流程页 = 步骤条+当前节点+导航。

**实体管理固定范式**：顶部操作栏（新建+搜索+过滤）→ Table（数据列+状态 Tag 列+操作列"查看|编辑|删除"）→ 分页器 → 弹窗/抽屉（新建表单 / 编辑预填 / 详情）。**见到"XX管理"就按这个来**，不要用卡片流、不要自创交互。

**弹窗**：确认弹窗 400px；表单弹窗 520px；详情 600px 或抽屉；**选择类操作（选素材/选人员）必须用带预览的弹窗/抽屉，禁止裸 Select**。

**数据展示**：时间完整格式 `YYYY-MM-DD HH:mm`；金额千分位+符号；状态用带色 Tag；数量带单位；空数据显示 `—` 或引导文案；列表默认时间倒序；长文本列表截断+悬停、详情完整。

## 四、交付前自检清单

- [ ] 文案：100% 中文、业务语言、无占位文字、表意清晰
- [ ] 交互：按钮全绑事件；选择控件可选可取消；流程有上一步；删除/提交有二次确认；菜单重复点击正确重置
- [ ] 数据：列表有搜索/过滤/分页且业务过滤；空态有引导；数字带单位、时间完整、状态有色
- [ ] CRUD：每个实体管理增删改查齐全；编辑预填；删除 Popconfirm；操作后有 message 反馈
- [ ] 一致性：同类弹窗/列表/空态一致
- [ ] 编译：`tsc --noEmit` 零错误；dev 启动无控制台报错；页面切换无白屏

## 五、子任务 Prompt 内嵌摘要（P3 生成 Prompt 时复制此块）

```
【质量红线（违反必返工）】
1. 用户可见文案 100% 中文，禁止英文术语和占位文字，Mock 数据要真实可信
2. 所有按钮绑定事件（至少 message.info 反馈）；删除/提交有二次确认
3. 列表页必须有：搜索 + 过滤 + 分页；数据按业务状态过滤展示
4. "管理"类页面必须有完整 CRUD（新建/查看/编辑预填/删除确认），用 Table+操作列范式
5. 选择类控件支持选中和取消；流程支持上一步/下一步/重置
6. 任务/流程类状态枚举 ≥3 态；状态用带色 Tag 展示
7. 时间格式 YYYY-MM-DD HH:mm；数字带单位；空数据显示 — 或引导文案
8. 与项目内同类组件保持行为和视觉一致
```
