# 数据安全与合规（脱敏 / 导出 / 水印 / 留痕）

> 政务与大型企业项目的验收高频项。**默认最小可见**：能脱敏就不明文，能不给就不展示。
> 与 `permission-guide.md`（字段级权限）、`feedback-patterns.md`（批量反馈）配合。

---

## 一、字段分级

| 级别 | 示例 | 默认展示 |
|---|---|---|
| 公开 | 单位名称、事项名称 | 明文 |
| 内部 | 内部编号、经办人 | 明文（登录后可见） |
| 敏感 | 手机号、邮箱、住址、车牌 | **脱敏**，按需展开 |
| 高敏 | 身份证号、银行卡号、健康/处罚记录 | 脱敏 + 展开需二次授权 + 留痕 |
| 禁止展示 | 密码、密钥、完整会话凭证 | 永不展示（连掩码都不给） |

---

## 二、脱敏规则（前端统一实现一份 `mask.ts`）

| 字段 | 规则 | 示例 |
|---|---|---|
| 手机号 | 保留前 3 后 4 | `138****1234` |
| 身份证 | 保留前 4 后 4，中间 `*` 位数与原文一致 | `1101**********1234` |
| 姓名 | 保留姓氏，名用 `*` | `张*` / `欧阳**` |
| 银行卡 | 仅留后 4 | `**** **** **** 1234` |
| 邮箱 | 保留首字符与域名 | `z***@example.com` |
| 地址 | 保留省市区，详细地址 `*` | `浙江省杭州市西湖区****` |
| 车牌 | 保留省份与后 2 位 | `浙A***2` |

```ts
export const mask = {
  phone: (v: string) => v.replace(/^(\d{3})\d{4}(\d{4})$/, '$1****$2'),
  idCard: (v: string) =>
    v.replace(/^(.{4}).*(.{4})$/, (_, a, b) => a + '*'.repeat(Math.max(0, v.length - 8)) + b),
  name: (v: string) => (v.length <= 1 ? v : v[0] + '*'.repeat(v.length - 1)),
  bankCard: (v: string) => v.replace(/\d(?=\d{4})/g, '*').replace(/(.{4})/g, '$1 ').trim(),
  email: (v: string) => v.replace(/^(.).*?(@.*)$/, '$1***$2'),
};
```

规则：

- 掩码字符统一用 `*`，位数与原文一致。
- **脱敏态禁止复制原值**：复制按钮在未展开时隐藏，或复制的就是脱敏串。
- 列表、详情、导出默认都脱敏；高敏字段默认不进导出。

## 三、按需展开（查看原值）

```vue
<span class="sensitive">
  {{ revealed ? row.idCard : mask.idCard(row.idCard) }}
  <a-button type="text" size="mini" @click="reveal('idCard', row.id)">
    {{ revealed ? '隐藏' : '查看' }}
  </a-button>
</span>
```

- 点击「查看」先调后端鉴权接口（不要前端判断完就直接解密），成功后返回明文并**记录审计日志**（谁、何时、看了哪条数据的哪个字段）。
- 高敏字段展开后 60 秒自动恢复脱敏，或离开页面即恢复。
- 无权限时不给「查看」按钮（按 `permission-guide.md` 三态）。

## 四、导出

| 要求 | 做法 |
|---|---|
| 导出内容与当前筛选一致 | 传当前筛选条件，不导全量 |
| 含敏感字段需二次确认 | 字段清单 + 「本次含 2 个敏感字段，将记录操作日志」 |
| 大批量走异步任务 | 见 `feedback-patterns.md`「长任务」 |
| 导出文件带水印 | 见下节 |
| 导出留痕 | 操作人、时间、条件、条数、字段范围 |

```vue
<a-modal v-model:visible="exportVisible" title="导出数据">
  <a-alert type="warning">本次导出包含「手机号、身份证号」，导出行为将记录操作日志。</a-alert>
  <a-checkbox-group v-model="fields">
    <a-checkbox value="name">姓名</a-checkbox>
    <a-checkbox value="phone">手机号</a-checkbox>
    <a-checkbox value="idCard">身份证号</a-checkbox>
  </a-checkbox-group>
  <p class="hint">导出 {{ total }} 条，预计 {{ estimate }} 秒</p>
</a-modal>
```

## 五、页面水印

- 涉密/内部系统统一用 `a-watermark`：内容 = `姓名 + 工号`（可选时间）。
- 水印覆盖内容区且不可被单页样式关闭；层级低于弹窗、高于表格。
- 透明度 0.08–0.12，不影响阅读，不要做成整屏文字墙。

```vue
<a-watermark
  :content="[`${user.name} ${user.employeeNo}`, dayjs().format('YYYY-MM-DD')]"
  :gap="[120, 120]"
>
  <router-view />
</a-watermark>
```

## 六、留痕（审计）

| 事件 | 是否必须留痕 |
|---|---|
| 查看高敏字段原文 | 必须 |
| 导出（含敏感字段） | 必须 |
| 删除 / 作废 / 批量操作 | 必须 |
| 权限变更 | 必须（后端） |
| 普通浏览列表 | 视合规要求 |

前端职责：详情页提供「操作日志」入口（`a-timeline`），展示谁在何时做了什么；没有日志接口时不要伪造。

---

## 七、自查清单

1. 敏感字段是否默认脱敏，且掩码位数与原文一致？
2. 展开原值是否走后端鉴权、留痕、并自动恢复脱敏？
3. 脱敏态是否禁止复制原值？
4. 导出是否跟随当前筛选、二次确认、留痕、带水印？
5. 内部/涉密系统是否统一水印且不可被页面关闭？
6. 详情页是否有操作日志入口（有接口才做）？
7. 是否有任何地方展示密码、密钥、完整凭证？（必须为零）
