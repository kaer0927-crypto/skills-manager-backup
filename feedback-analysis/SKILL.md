# Skill：反馈分析（feedback-analysis）

## 触发词
/feedback-analysis

## 一句话描述
批量分析 100+ 条用户反馈，输出 1 份含分析报告 + P0/P1/P2 产品机会清单的 Markdown 文档（含分类、情感、洞察、抽样校验），不输出多文件。

## 输入约定
- 必填：反馈文件相对/绝对路径（Markdown 表格 或 CSV，含 100+ 条原始反馈，字段含日期/来源/原文/用户角色）
- 可选：产品背景信息文件（含产品类型、用户来源、分类标准）

## 执行步骤
1. 读取反馈文件，识别字段（编号 / 日期 / 来源 / 用户角色 / 反馈原文）
2. 按"分类标准表"给每条反馈贴 3 个标签：功能模块 / 反馈类型 / 情感倾向
3. 统计 Top 5 高频问题（按功能模块 + 反馈类型聚合，含占比和典型原文）
4. 计算整体情感三分类占比 + 按功能模块的情感分布
5. 做跨群对比分析（付费 vs 免费、新用户 vs 老用户、应用商店 vs 客服）
6. 提炼 5-8 条产品洞察（现象 → 归因 → 动作建议，三段式）
7. 转化为 8-15 条产品机会，每条用 3 维评估（频率 × 强度 × 商业价值）打 1-5 分
8. 按总分排序，前 3 名为 P0，4-8 名为 P1，9 名后为 P2
9. 自动从分类结果中抽 10 条，让用户人工校验，校验结果写入"抽样校验记录"
10. 输出 1 份 Markdown 文档（见"输出契约"）

## 输出契约
输出 1 个 Markdown 文件，路径 = `{输入文件目录}/feedback_report_{YYYYMMDD}.md`，包含以下 5 大板块（顺序固定）：

#### 1. 元信息
- 数据来源、时间范围、样本量、用户角色分布
- 分类标准表 + 情感判断规则

#### 2. Top N 高频问题（按功能模块 + 反馈类型聚合）
每个 Top 问题包含：
- 排名 + 问题名
- 占比 %
- 典型反馈原文 2-3 条
- 用户角色分布

#### 3. 情感分析
- 整体三分类占比（积极 / 中性 / 消极）
- 按功能模块的情感分布（哪类问题负面最重）
- 跨群对比（付费 vs 免费、新用户 vs 老用户、应用商店 vs 客服）

#### 4. 产品洞察（5-8 条）
每条洞察含三段：
- **现象**：{数据 + 占比 + 典型原文}
- **归因**：{为什么会这样，假设 1-2 个原因}
- **动作建议**：{产品应该做什么}

#### 5. 产品机会清单（8-15 条，含 P0/P1/P2）
Markdown 表格 + 每条详细描述：

| 编号 | 机会名称 | 关联洞察 | 影响用户 | 痛点强度 | 商业价值 | 优先级 |
|---|---|---|---|---|---|---|
| O1 | {一句话} | Top N | {量级} | 1-5 | 1-5 | P0/P1/P2 |

按 P0 → P1 → P2 排序，每条 1 段详细描述（含"做什么 + 为什么 + 怎么做"）。

文末必须含：
**抽样校验记录**（10 条样本 + 用户人工判断 + 准确率）

---

## 约束
- **输出形态**：1 个 Markdown 文件（分析报告 + 机会清单合并在同一文件），不输出多文件
- **分类标准**：必须使用下方"分类标准表"，禁止自由发挥
- **情感粒度**：三分类（积极 / 中性 / 消极），每条反馈必选 1 个
- **抽样校验**：自动抽 10 条让用户人工标注，准确率 < 70% 必须在报告末尾标"❌ 结果不可信，建议重跑"
- **P0 数量上限**：不超过 3 条，超出降为 P1
- **机会数范围**：8-15 条，不在此范围提示用户调整
- **数据脱敏**：输出时不重复用户 ID / 手机号 / 邮箱
- **洞察三段式**：每条洞察必须含"现象 → 归因 → 动作建议"
- **对比分析必须出**：报告里必须出现至少 2 个对比维度（付费/免费、新/老、商店/客服）

## 分类标准表（写进 SKILL.md 的 C 段，AI 必须严格按此分类）

## 功能模块（必选 1 个）
1. 账号与登录
2. 记账功能
3. 报表与统计
4. 同步与备份
5. 通知与提醒
6. 其他

## 反馈类型（必选 1 个）
1. Bug：功能故障、崩溃、数据错误
2. 需求：希望增加新功能
3. 体验：设计不合理、性能差、流程繁琐
4. 咨询：不会用、找不到入口

## 情感三分类（必选 1 个）
- 积极：表达满意、推荐、感谢、惊喜
- 中性：陈述事实、提问、不带情绪
- 消极：表达不满、失望、愤怒、想要离开

判断规则：
1. 出现"差""垃圾""再也不用""退钱"等词 → 消极
2. 出现"不错""挺好""感谢""喜欢"等词 → 积极
3. 描述问题但不强烈表达不满 → 中性
4. 有"但是""不过""如果能"等转折 → 看后半句
