# P5 功能清单迭代

> **定位**：合并 V1 + Delta + 客户新需求 → 新版功能清单，产出发客户确认用的 xlsx。
> **产出**：`study/03_功能模块拆解清单_VN.md` + `[项目名]功能模块拆解清单_VN.xlsx`

## 前置输入

- `study/01_功能模块拆解.md`（V1 基准，缺失则先走 P2）
- Delta 清单（P4 产出，如有）
- 客户新增需求 / 修改意见（如有）

**跳过条件**：无 Delta、无新需求、无修改意见 → 跳过，V1 直接进 P6。

## 执行步骤

### Step 5.1 — 变更源汇总

| 来源 | 内容 | 数量 |
|------|------|:---:|
| P4 Delta | 参考平台对标出的新增/调整 | X |
| 客户新需求 | V1 反馈后新提出 | X |
| 内部发现 | 分析过程发现的遗漏 | X |
| 优先级调整 | 升级/降级的功能点 | X |

### Step 5.2 — 合并整理

V1 + 全部变更合并为 VN。**每个功能点必须带来源标签**：

`原有`（V1 未动）/ `参考补充`（P4 引入）/ `新增需求`（客户或内部新提）/ `合并优化`（多源优化描述）/ `优先级调整`（标注 from → to）

### Step 5.3 — 版本对比摘要

| 维度 | V1 | VN | 变更说明 |
|------|----|----|---------|
| 模块数量 / 功能点总数 / P0 功能点 | | | 净增 Z 个；Top 3 关键变更 |

### Step 5.4 — 文档输出

1. `study/03_功能模块拆解清单_VN.md`（版本变更说明 + 完整清单表）
2. **xlsx 生成**（发客户确认用），按优先链：
   - 本技能自带脚本：`python3 scripts/md_tables_to_xlsx.py study/03_功能模块拆解清单_VN.md -o [项目名]功能模块拆解清单_VN.xlsx`（依赖 openpyxl，缺失时 `pip install openpyxl`）
   - 或环境已安装 `minimax-xlsx` 技能 → 按其规程
   - 都不可用 → 交付 md + 提示用 WPS/Excel 导入 markdown 表格

**xlsx 必含字段**：模块编号 | 模块名称 | 子功能编号 | 子功能名称 | 功能描述（≥20字）| 用户角色 | 优先级 | 来源 | 客户意见（留空列，供客户填写）

## 交付物

- `study/03_功能模块拆解清单_VN.md` + `[项目名]功能模块拆解清单_VN.xlsx`

## 注意

- xlsx 是给客户逐行标注用的（「不要」「需要改」「不理解」），**必须留"客户意见"空列**
- `参考补充` 类发送时主动告知客户：「这些是参考同类平台补充的，请确认是否需要」

🔴 GATE：输出版本对比摘要，等用户确认后进入 P6。
